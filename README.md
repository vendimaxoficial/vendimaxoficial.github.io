# Rally Creators Vendimax

Landing page oficial do Rally Creators Vendimax.

**Site:** https://vendimaxoficial.github.io/

## Campanha
- Meta coletiva: R$ 6.000 em GMV
- Meta individual: 100 vídeos até 30/10
- 1º lugar: Microfone Hollyland
- 2º lugar: R$ 150 via Pix
- 3º lugar: R$ 100 via Pix
- Ranking por GMV individual do perfil cadastrado
- Não é permitido somar GMV de perfis diferentes

## Leads
O formulário envia os cadastros para **marketing.vendimax@outlook.com** por meio do FormSubmit.

Na primeira submissão, o FormSubmit envia um e-mail de ativação ao endereço acima. Essa confirmação precisa ser feita uma única vez.

## Atualização de GMV
O progresso exibido no site fica configurado no final do `index.html` pelas constantes `CURRENT_GMV` e `TARGET_GMV`.
